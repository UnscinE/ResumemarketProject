> Professional Profile & Resume Discovery Platform

ResumeMarket is a modern platform that helps candidates showcase their skills, projects, experiences, and professional identity beyond a traditional resume. Recruiters can discover talents through portfolios, skills, project experiences, and video introductions.

---

## ✨ Features

### 👨‍💻 Candidate

* Create Professional Profile
* Upload Resume (PDF)
* Portfolio Showcase
* Project Timeline
* Skills Management
* Video Introduction
* Public Profile Sharing

### 🏢 Recruiter / HR

* Candidate Search
* Advanced Filters
* Portfolio Review
* Resume Viewer
* Save Favorite Candidates
* Candidate Contact System

### ⚙️ Admin

* User Management
* Content Moderation
* Platform Analytics
* System Configuration

## 🎯 Project Goals

The platform aims to solve common recruitment challenges:

### Candidate Problems

* Resume does not fully represent capabilities
* Limited opportunities to showcase projects
* Difficult to stand out among applicants

### Recruiter Problems

* Hard to evaluate candidates from resumes only
* Time-consuming screening process
* Limited visibility into real skills and portfolios
